# 🕌 سكينة (Sakinah) — تطبيق الأذكار والأدعية الإسلامية

> تطبيق أندرويد متكامل وشامل للأذكار والأدعية الإسلامية مبني بأحدث تقنيات أندرويد الحديثة: Kotlin, Jetpack Compose, Material Design 3, Room Database, Jetpack Glance, WorkManager, Hilt, و Google Downloadable Fonts.

---

## ✨ المميزات الرئيسية والفريدة

1. **الواجهة الذكية حسب السياق والوقت (Smart Hero Card):**
   تتغير تلقائياً حسب الوقت وساعات اليوم (أذكار الصباح بعد الفجر، أذكار المساء بعد العصر، أذكار النوم ليلاً، وسُنن وصلاة على النبي ﷺ يوم الجمعة) وتفتح الورد بلمسة واحدة.

2. **المسبحة التفاعلية باللمس الأعمى (Blind-Touch Gesture Tasbih):**
   شاشة كاملة مخصصة للتسبيح باللمس في أي مكان دون النظر للشاشة، مع إيماءات السحب للتبديل وأنماط اهتزاز لمسي (Haptic Feedback) عند 33 و 66 و 100.

3. **وضع القراءة الغامر (Zen Focus Mode):**
   إخفاء تام لجميع الأزرار والقوائم للإبقاء على النص فقط، مع منع انطفاء الشاشة (Keep Screen On) وميزة التمرير التلقائي البطيء (Auto-Scroll) بعداد شفاف.

4. **دليل "بماذا تشعر الآن؟" (Emotional Companion):**
   اختيار الحالة القلبية أو النفسية (قلق، حزن، خوف، هم، طلب رزق، شكر، استخارة، مرض) ليقترح التطبيق باقة أدعية مختارة تلامس الوجدان.

5. **باني الورد الشخصي (Custom Wird Builder):**
   تجميع الأذكار المفضلة وإضافة أدعية خاصة يكتبها المستخدم بنفسه مع تحديد عدد تكرارها.

6. **نظام الثيمات الأربعة المدروسة بعناية (WCAG AA):**
   - **النهاري الهادئ (Warm Paper):** خلفية ورقية مريحة للعين (`#FAF8F5`) ولمسات زمردية.
   - **الليلي المريح (Soft Slate Dark):** رمادي مزرق للقراءة الليلية (`#121619`).
   - **الأسود النقي (Pure OLED Black):** أسود نقي (`#000000`) لتوفير البطارية وقراءة الفجر.
   - **الألوان الديناميكية (Material You):** تتكيف تلقائياً مع خلفية هاتف المستخدم (Android 12+).

7. **الويدجت التفاعلي للشاشة الرئيسية (Jetpack Glance):**
   ويدجت ذكي يتغير محتواه وذكره حسب وقت اليوم، مع إمكانية التسبيح المباشر بنقرة واحدة من الشاشة الرئيسية.

8. **نظام الإشعارات الذكية والتسبيح من الإشعار:**
   جدولة يومية دقيقة عبر `WorkManager` وزر تسبيح تفاعلي فوري داخل الإشعار ذاته، مع دليل إرشادي لكبرى شركات الهواتف (Samsung, Xiaomi, Oppo, Huawei) لتجاوز قيود البطارية الصارمة.

9. **مولد بطاقات المشاركة (Zikr Card Generator):**
   تحويل أي ذكر إلى بطاقة تصميمية بدقة عالية (1080x1350) ومشاركتها مباشرة عبر واتساب وشبكات التواصل.

10. **النسخ الاحتياطي والاستعادة (JSON Backup & Restore):**
    تصدير واستيراد الأذكار المفضلة والمخصصة بأمان.

## 🛠️ البنية التقنية (Tech Stack)

- **اللغة:** Kotlin 2.1.0
- **إطار العمل:** Jetpack Compose + Compose Compiler 2.1.0
- **المعمارية:** Clean Architecture + MVVM + Unidirectional Data Flow (UDF)
- **قاعدة البيانات:** Room Database 2.6.1 مع Pre-populated Seed JSON تلقائي
- **حقن التبعيات:** Dagger Hilt 2.52
- **الحفظ المحلي:** Jetpack DataStore Preferences 1.1.1
- **المهام الخلفية:** AndroidX WorkManager 2.10.0 + AlarmManager
- **الويدجت:** Jetpack Glance AppWidget 1.1.1
- **الخطوط:** Google Downloadable Fonts (Cairo & Amiri) مع Fallback خطوط النظام
- **التوافق:** `minSdk = 23` (Android 6.0 Marshmallow) وحتى `targetSdk = 35` (Android 15)

## 🚀 كيفية فتح المشروع وتشغيله في Android Studio

1. **فتح المشروع:**
   - افتح **Android Studio** (نسخة Ladybug 2024.2.1 أو أحدث).
   - اختر **File -> Open** وحدد المجلد: `d:\SakinahApp`.

2. **مزامنة Gradle (Gradle Sync):**
   - سيتعرف Android Studio على ملفات المشروع ومجلد `gradle/libs.versions.toml`.
   - اضغط على **Sync Project with Gradle Files**.

3. **التشغيل (Run):**
   - اختر محاكي (Emulator) أو هاتف حقيقي يعمل بـ Android 6.0 أو أحدث.
   - اضغط على زر **Run (Shift + F10)**.

> [!TIP]
> قاعدة البيانات سيتم ملؤها بجميع الأذكار تلقائياً في الخلفية عند أول تشغيل للتطبيق عبر `res/raw/azkar_seed.json`.
